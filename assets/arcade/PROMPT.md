# Rank artwork brief

Generated with the built-in image tool. Use case: stylized-concept. One transparent
4-by-2 rank atlas, original chunky beveled arcade medals inspired by the supplied
gold/ivory S with red dimensional rim. Top row D/C/B/A, bottom S/SS/SSS/empty;
equal square cells, centered with transparent padding, no captions or watermark.
Steel D, bronze C, silver B, gold A, gold/red S, increasingly luminous SS and SSS.
Front-facing orthographic, crisp metallic reflections, genuine transparent alpha.

Replace ranks.png with another atlas using the same cell order. Replace hover.wav,
click.wav, transition.wav and rank-up.wav with your own cues, then rebuild. The WAVs
are original deterministic placeholders from scripts/make-ui-sounds.mjs. Assets
are embedded in runtime bundles, so installation still replaces only the existing
three Obsidian plugin files; there is no journal or recording upload.
# Exact generation prompt

Use case: stylized-concept. Asset type: one production UI rank sprite atlas for Color Sprint, transparent PNG. The attached S is a STYLE REFERENCE only, not an edit target. Generate an original set of chunky arcade rank medals: glossy beveled serif lettering with ivory highlights, polished gold/chrome faces, deep crimson enamel outlines and dark dimensional edges, crisp readable silhouettes, compatible with a dark cyan sci-fi HUD. One atlas, exact 4-column by 2-row grid of EQUAL SQUARE CELLS, ideally 2048 by 1024 pixels. Each badge is fully contained and centered in its own cell with 12 percent transparent padding, no overlap. Top row left to right exact text: D, C, B, A. Bottom row left to right exact text: S, SS, SSS, then EMPTY transparent cell. All text uppercase, exactly these letters, no numbers, captions, labels or watermarks. D uses brushed steel, C bronze, B bright silver, A gold, S gold with rich red rim, SS brighter gold and red double-flared rim, SSS the most luminous gold/ivory with red jeweled rim. Same visual family and viewing angle for all seven badges. SS and SSS must fit within their square cells at the same generous overall badge footprint. Orthographic front-facing, large high-quality game sprites, tasteful metallic reflections. Genuinely transparent alpha around the isolated medals, not black background, not a checkerboard image. No particle effects baked outside the cell; those are added by the app.
